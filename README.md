# Розробка комп'ютерних ігор - лабораторні роботи

Драганчук Ілля, МЕГУ, спеціальність 121 Інженерія програмного забезпечення.

Рушій: Unity 6 (6000.0.85f2).

| Робота | Папка | Зміст |
|---|---|---|
| ЛР1 | [2D/LR1](2D/LR1) | Платформер: тайлсет, палітра тайлів, рівень на шарах Tilemap, анімований герой |
| ЛР2 | [2D/LR2](2D/LR2) | Платформер: рух, стрибок і розворот героя (C#), камера за героєм, перезапуск після падіння, безкінечний рівень і фон |
| ЛР3 | [2D/LR3](2D/LR3) | Пригодницька гра з Ruby: налаштування проєкту, рух героїні через Input Action, незалежність від частоти кадрів |
| ЛР4 | [2D/LR4](2D/LR4) | Ігрове середовище та фізика: Tilemap, перешкоди, Rigidbody 2D і колайдери |
| ЛР5 | [2D/LR5](2D/LR5) | Система здоров'я, зони шкоди, предмети для лікування, смужка здоров'я (UI Toolkit) |
| ЛР6 | [2D/LR6](2D/LR6) | Вороги-роботи, снаряди, NPC і діалог, анімації, лічильник полагоджених роботів |
| ЛР7 | [2D/LR7](2D/LR7) | Динамічна камера Cinemachine, музика і звуки, ефекти частинок |
| ЛР8 | [3D/LR8](3D/LR8) | 3D локація природи на Terrain: рельєф, текстури, озеро, скелі, трава, дерево з Tree Editor, вільна камера |
| ЛР9-10 | [3D/LR9-10](3D/LR9-10) | Персонаж з MakeHuman і Knight: риг Humanoid, один Animator Controller на двох (Blend Tree, стрибок, удар, падіння) |
| ЛР11 | [3D/LR11](3D/LR11) | Політ: локація з горами і скелями, префаб літака, час польоту на екрані, перезапуск сцени після аварії |
| ЛР12 | [3D/LR12](3D/LR12) | Гонки: траса-кільце, вейпоінти, суперники зі штучним інтелектом, кола, місця, час і фініш |

Щоб відкрити проєкт: Unity Hub - Add - вибрати папку роботи (наприклад 2D/LR1). Скріни запуску лежать у папці Screenshots кожної роботи.

Керування в платформері: A / D або стрілки - рух, пробіл - стрибок.

Керування в пригодницькій грі: WASD або стрілки - рух, C - кинути деталь у робота, X - поговорити з NPC.

Готові збірки для Windows (exe) лежать у розділі Releases. Асети пригодницької гри взято з навчального пакета Unity (Adventure Game: Robot Repair), ліцензія Unity Companion License.

Керування камерою в 3D локації (ЛР8): WASD - рух, затиснуте коліщатко миші - поворот, прокручування - висота.

Керування персонажами (ЛР9-10): WASD - рух, пробіл - стрибок, ліва кнопка миші або F - удар, H - отримати удар, K - впасти, R - піднятись, Tab - змінити персонажа.

Керування літаком (ЛР11): A / D - крен, W / S - ніс униз / угору, ліва кнопка миші або Ctrl - гальма.

Керування в гонках (ЛР12): W / S - газ і гальмо, A / D - кермо, пробіл - ручне гальмо, Backspace - повернутись на трасу, R - почати заново.
